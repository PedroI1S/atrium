### Full superlinear audit of `app/src/chat/markdown.ts`
- `parseMarkdown` (`replace(/\r\n?/g, "\n").split("\n")`): single linear normalization and split pass; O(N).
- `isBlank`, `parseFenceOpen`, `isFenceClose`, `parseSetextHeading`, `parseAtxHeading`, `isThematicBreak`, `isTableDelimiter`: all deterministic single-pass index scans with no regex backtracking; O(len(line)).
- `QUOTE`, `BULLET`, `ORDERED` (`listMarker`): anchored at `^` with fixed maximum match lengths (5, 8, and 17 characters); O(1) per line.
- `expandTabs`: single `includes("\t")` + `replace(/\t/g, "    ")`; once expanded at depth 0, recursive list levels (`<= MAX_DEPTH = 12`) see no tabs, so total growth is at most 4x; O(N).
- `startsBlock`: calls only linear/O(1) helpers; each line is tested a constant number of times per nesting depth (`<= MAX_DEPTH = 12`); O(N).

- `parseLines` — fenced code, ATX/setext headings, thematic breaks, paragraphs: monotonic line index `i`, index-based fence indent stripping (no per-line `new RegExp`), single `join("\n")` per block; O(N).
- `parseLines` — blockquotes & lists: monotonic line index `i`, trailing blank pops visit each pushed empty line once, recursion capped at `MAX_DEPTH = 12`; O(N).
- `parseLines` — GFM tables (**fixed during audit**): previously padded every short row out to `head.length` (`O(H*R)` = O(N^2) on wide headers with many short rows); now iterates only `k < Math.min(cells.length, head.length)` so total parsed cells across all rows is bounded by input cells; O(N).
- `List`, `InlineSeq` (`singleSeq`, `appendSeq`, `concatNodes`), `seqToArray`: O(1) list/sequence ops; each cut node is collapsed into one node; `seqToArray` now joins contiguous text runs via `textParts: string[]` once and visits each `InlineCell` at most once (depth > `MAX_INLINE_DEPTH = 16` stays flattened in O(1)); O(N).
- `parseInline` text buffer & soft/hard line breaks (**Finding 1 fixed**): plain text runs sliced directly into `bufParts: string[]`, contiguous trailing spaces counted in `trailingSpaces`, soft/hard breaks never inspect or flatten `bufParts`, single `join("")` on `flush()`; O(N).
- `parseInline` backtick code spans: lazy single-pass index of maximal backtick runs by length with monotonic per-length cursors; matched spans skip `i = close + n`; O(N).
- `parseInline` `AUTOLINK` & `EMAIL` (**hardened during audit**): sticky `/y` regexes with bounded quantifiers (`[^\s<>]{0,4096}`, disjoint local/domain-label classes capped at 254 local chars and 127 labels), eliminating per-`<` `s.slice` copies and stopping immediately at `<` or whitespace; O(N).
- `parseInline` brackets (`[`, `![`, `]`) & `linkTail`: `activeLinks` stack visits each `[` at most once (never scanning `![`); `lastParen` computed at most once; `<...>` and title scans use monotonic `angleEnd`/`parenTitleEnd`/`dquoteTitleEnd`/`squoteTitleEnd` plus `failedAfterDest`/`failedAfterTitle` caches; bare destination paren depth caps at 32 (so any failing call crosses at most 32 later failing `](`s before returning `null`), with deferred single slice on success; O(N).
- `flanking`, `isWs`, `isPunctuation`, `processEmphasis`: O(1) flanking checks; `openersBottom` tracks monotonic node `seq` across 18 fixed delimiter keys; successful matches cut every walked inner node out of the list and flatten beyond `MAX_INLINE_DEPTH = 16` in O(1); O(N).
- `linkify` (`BARE_URL`) & `mapText`: single negated-class `matchAll` pass, single paren-count pass + counter-based end-index trim + single slice per URL; `mapText` recursion bounded by `MAX_INLINE_DEPTH = 16`; O(N).
- `plainText`: iterative stack traversal appending to `out` without ever inspecting `out` while growing (preserving O(1) per-level ConsString accumulation on nested images `![a ![b](u)](u)` so total work stays O(N)).
