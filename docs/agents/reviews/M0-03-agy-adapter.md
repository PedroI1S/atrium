## Reviewer's report
**Verdict: rework.** The live fixtures establish useful happy-path behavior, but the adapter still cannot guarantee pre-execution gating, and several lifecycle and recording checks miss real failures. No files were modified or prohibited examples run. Clippy was blocked by the read-only build lock; tests were not run because the suite invokes the prohibited examples internally.

1. **Blocker — Config validation does not close the fail-open race.** [adapter.rs:260](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/adapter.rs:260), [bridge.rs:936](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/bridge.rs:936). Validation and `agy` loading the config are separate operations. Mode `0600`/`0700` does not prevent the provider or tools running as the same user from replacing it; metadata inspection and reading also race. A config can pass validation and become malformed before `agy` reads it, allowing execution before the tripwire detects anything. **Fix:** require provider-side fail-closed loading or protect the config from the provider through an enforced filesystem boundary. Until then, refuse this unsafe host configuration and stop advertising `AllToolCalls`.

2. **Major — The tripwire’s aggregate counters can conceal ungated execution.** [adapter.rs:593](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/adapter.rs:593). Any recorded `allow` increases session-wide credit without binding it to the executed tool or arguments. The live question fixture supplies a concrete surplus: its hook returns `allow`, but its native step is `unknown`, so no executed tool consumes that credit. A later ungated tool can finish without triggering the check. Replies are also credited before socket delivery succeeds. **Fix:** correlate successful hook responses with individual calls using session, native step identity, tool, and canonical arguments; consume each authorization once.

3. **Major — `ask_question` bypasses the gate unconditionally.** [bridge.rs:409](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/bridge.rs:409). Valid question requests return before `gate.check`, and `AnswerQuestion` produces `allow` even if the configured gate would deny every call. This directly contradicts the frozen gating contract. **Fix:** evaluate the gate before entering the question-answer flow, respecting Deny and Ask decisions.

4. **Major — A rejected approval command can still create a retry grant.** [adapter.rs:428](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/adapter.rs:428), [normalizer.rs:746](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/normalizer.rs:746). In `DenyAndRetry`, `result` cancels the normalizer’s request but leaves the bridge approval pending. A subsequent Allow emits “unknown or already resolved” from the normalizer, yet the actor still calls `bridge.resolve_approval`, issuing a grant. **Fix:** give request validity one authoritative owner, synchronize cancellation into the bridge, and never forward rejected commands. Test Allow after the initial denied turn completes.

5. **Major — Live multi-turn usage violates per-turn semantics.** [normalizer.rs:771](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/normalizer.rs:771). The live fixture’s second response step reports **6,975 input / 32 output** tokens, while its `result` reports cumulative **13,842 / 65**. The normalizer chooses that cumulative result as turn-two usage, double-counting turn one when consumers sum turns. **Fix:** convert cumulative result counters to turn deltas, with explicit handling for resumed conversations, and assert those exact fixture totals.

6. **Major — The question test accepts an answer that the provider did not receive.** [bridge.rs:296](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/bridge.rs:296), [record.rs:666](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/examples/record.rs:666). Answers are placed in an allow reply’s `reason`. The live fixture answers Debug locally, but the provider responds that the user skipped selecting a profile. The expectation passes solely because the adapter emitted `RequestResolved::Answered`. **Fix:** establish a supported answer-delivery mechanism and verify provider acknowledgment; otherwise document structured questions as unsupported.

7. **Major — A blocked stdin write prevents Interrupt and Shutdown.** [adapter.rs:579](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/adapter.rs:579). The actor awaits `write_all` inside command handling. If the provider stops reading stdin and a message fills the pipe, execution never returns to the supposedly prioritized `select!`. **Fix:** use a bounded, cancellable writer task or retain pending writes within the main selection loop. Test with a child that never reads stdin and a message exceeding pipe capacity.

8. **Major — Shutdown and bypass abort leave tool descendants running.** [adapter.rs:539](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/adapter.rs:539). SIGINT, SIGTERM, and `child.kill()` target only the direct child. Shell commands and their descendants can survive after `SessionEnded`, including after a gate-bypass abort. **Fix:** create a dedicated process group, signal the group on interruption and termination, and verify both child reaping and descendant termination.

9. **Major — Hook connections outlive their helper and bridge.** [bridge.rs:214](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/bridge.rs:214), [bridge.rs:338](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/bridge.rs:338). Connection tasks are detached; bridge Drop aborts only the listener. An unanswered Ask retains its own state and responder indefinitely, even after the helper’s **25-second** timeout. Meanwhile `agy` is configured for **300 seconds**, and a late local approval can be reported Approved although the helper already denied execution. **Fix:** track and join connection tasks, propagate cancellation and disconnects, expire pending requests exactly once, and derive coordinated bridge/helper/provider deadlines. The drop test currently proves only the client’s eventual timeout denial.

10. **Major — Saturated shutdown silently discards closing events.** [adapter.rs:565](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/adapter.rs:565). Final delivery is abandoned after 50 ms. If the receiver remains full, pending tool/request closures and `SessionEnded` are dropped, so a later reader observes channel closure without the required lifecycle ending. **Fix:** decouple process cleanup from reliable bounded event delivery, preserving terminal events until the receiver drains or disconnects.

11. **Major — The saturation test does not establish the required guarantee.** [bridge_and_saturation.rs:542](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/tests/bridge_and_saturation.rs:542), [bridge_and_saturation.rs:598](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/tests/bridge_and_saturation.rs:598). Flood records omit the required `step_update` wrapper and become `Unmapped`, leaving no active turn. The test begins draining immediately after queuing Interrupt and Shutdown, does not observe Interrupt independently, and checks neither reaping nor leftover tasks/processes. **Fix:** emit valid records, establish saturation explicitly, keep events unread until cleanup is independently confirmed, and verify Interrupt, Shutdown, reaping, and task termination.

12. **Major — Streamed path fragments still leak the machine identifier.** [sanitize.rs:79](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/sanitize.rs:79), [tool-read.events.json:131](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/fixtures/agents/agy/tool-read.events.json:131). Sanitizing each delta independently leaves the reconstructed URL containing `h2jnhf54fb3wcbbk9xfdy6w0000gn/T/...`. Partial replacement changes the prefix to `/private/scratch-tmp`, which also evades the cleanliness check. **Fix:** sanitize streamed text with cross-delta context while preserving delta/completion consistency, regenerate the affected fixture, and test every split position of sensitive paths.

13. **Major — The raw secret check misses JSON-escaped disclosure.** [record.rs:735](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/examples/record.rs:735). The check searches serialized records for the literal secret. A provider stdout JSON string containing the secret through Unicode escapes passes this check; subsequent sanitization decodes and redacts it, erasing evidence before expectations run. **Fix:** inspect decoded provider values and reconstructed message text before redaction. Add escaped-secret and fragmented-secret cases.

14. **Major — Configured MCP servers are silently unused.** [adapter.rs:222](/Users/pedro/Documents/atrium-wt/M0-03-agy-adapter/spikes/agent-agy/src/adapter.rs:222). The adapter writes MCP configuration into the session directory but never gives `agy` a supported mechanism to discover it. The default disables `--add-dir`, and the exported Atrium environment variables do not inject MCP configuration. **Fix:** implement and verify an actual per-session discovery mechanism; until then, reject nonempty `mcp_servers` explicitly and correct the handoff’s injection claim.
